# Chorded input (CharaChorder path)

Chords arrive as machine-fast words over plain HID — no driver. The vocabulary is prefix-free — asserted by a conformance vector, because that property is what the latency claim rests on — so a known word commits on its last keystroke (⚡, IPA 1, TTC ≈ 0). The same word typed slowly still works, flagged ⌨ at honest cost. Select with the pointer, act with the chord. The whole vocabulary is driven twice here, so the TTC percentile below is a distribution rather than a handful of numbers.
